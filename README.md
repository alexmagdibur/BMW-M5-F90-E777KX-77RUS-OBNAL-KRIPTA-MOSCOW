# ZOV AUTO — симулятор гоночной команды

Консольная игра на Java, в которой вы руководите гоночной командой: распоряжаетесь бюджетом, покупаете детали, нанимаете пилотов и инженеров, собираете болиды и отправляете их на трассу. Результат зависит от конфигурации машины, команды, тактики, особенностей трассы и погоды.

Проект начинался как учебная работа по объектно ориентированному программированию и вырос в симулятор с несколькими режимами гонок, сохранениями и редактором трасс.

## Возможности

- **Управление командой:** стартовый бюджет, покупки, найм персонала и просмотр состава.
- **Сборка болидов:** компоненты разных типов, проверка совместимости и обслуживание машины.
- **Обычные гонки:** выбор трассы, болида, пилота, инженера и тактики; варианты без пит-стопов, с одним или двумя пит-стопами.
- **Динамические события:** погода, износ деталей, риск инцидентов и схода с дистанции.
- **Режим выживания:** пошаговая гонка с обгонами, соперниками и игровым оружием.
- **Редактор трасс:** создание собственных трасс перед началом игры.
- **Сохранения:** ручное сохранение, автосохранение и загрузка команды при следующем запуске.
- **Особая механика затмения:** при солнечном затмении в игре появляется возможность искать оборотней среди персонала.

## Как играть

После запуска введите название команды. Если для неё уже есть сохранения, игра предложит начать заново или загрузить одно из них. Затем можно открыть редактор трасс и перейти в главное меню.

Первый заезд удобно подготовить так:

1. Купите компоненты для болида.
2. Наймите инженера и пилота.
3. Соберите болид.
4. Выберите «Начать гонку», режим и трассу.
5. Назначьте болид, пилота и инженера, затем выберите тактику.

После гонки можно посмотреть результат и состояние машины. Изношенные компоненты обслуживаются через отдельный пункт меню. Перед следующим запуском сохраните игру вручную или воспользуйтесь созданным автосохранением.

## Запуск

Понадобятся **JDK 17 или новее** и **Maven**. Файл `pom.xml` расположен в каталоге `src`, поэтому команды ниже выполняются из корня репозитория.

```bash
git clone https://github.com/alexmagdibur/BMW-M5-F90-E777KX-77RUS-OBNAL-KRIPTA-MOSCOW.git
cd BMW-M5-F90-E777KX-77RUS-OBNAL-KRIPTA-MOSCOW

mvn -f src/pom.xml compile
java -cp src/target/classes app.Main
```

Для запуска тестов:

```bash
mvn -f src/pom.xml test
```

Сохранения создаются в каталоге `saves/` относительно папки, из которой запущена программа. Запускайте игру из одного и того же каталога, чтобы она находила прежние сохранения.

## Структура проекта

```text
src/
├── pom.xml               # Сборка Maven и настройки тестов
├── game/
│   ├── app/              # Точка входа
│   ├── data/             # Каталоги игровых данных
│   ├── domain/           # Команда, болиды, трассы и другие сущности
│   ├── saving/           # Форматы и работа с файлами сохранений
│   ├── service/          # Сборка, покупки, гонки, износ и другие механики
│   ├── ui/               # Консольное меню и редактор трасс
│   └── util/             # Вспомогательный код
└── test/                 # Тесты
```

Java 17, Maven, JUnit 5. Интерфейс работает в терминале; графическая оболочка для запуска не нужна.

Проект учебный, а игровые события и названия носят вымышленный характер.
